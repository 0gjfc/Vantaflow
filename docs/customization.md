## Theme, overlay, homebrew app, shell replacement

| Term | Meaning |
|---|---|
| Theme | Changes the look the system offers to change: wallpaper, colours, sounds. The system home screen stays the same program. |
| Overlay | Draws extra information on top of the system or a game (FPS counter, Title ID labels, cheat menu). Nothing underneath is replaced. |
| Homebrew application | A separate application, like Itemzflow or VantaFlow on a console, that you open from the home screen. It can look like a dashboard, but the system home screen keeps running behind it. |
| Home redirect | A homebrew option that opens a homebrew app when the home screen would normally appear (Itemzflow 'Home_Redirection', etaHEN 'StartOption'). The system shell still runs underneath; it is not replaced. |
| System shell replacement | Swapping the system home screen program (the shell) for another one. No documented method was found for PS4 or PS5, so VantaFlow does not claim it. |

**What this means for VantaFlow:** on a console, VantaFlow can realistically be a homebrew application (like Itemzflow), optionally opened through a home redirect that GoldHEN/Itemzflow or etaHEN already document. It does not and cannot claim to replace the PlayStation dashboard: no documented method exists for that.

Areas covered: backgrounds and themes, game artwork, game library presentation, home screen appearance, application presentation, interface overlays, custom menus and profile appearance.
